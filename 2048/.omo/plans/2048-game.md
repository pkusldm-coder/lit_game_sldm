# 2048 Web Game Development Plan

## TL;DR

> **Quick Summary**: Build a classic 2048 sliding-tile puzzle game with React + TypeScript + Vite, featuring three difficulty modes (Easy 6×6, Normal 4×4, Hard 4×4+8), drag-to-trash eraser mechanic (3 per game), per-difficulty high scores, mobile touch support, and unit-tested core logic.
>
> **Deliverables**:
> - Complete playable 2048 game with 3 difficulty levels
> - Drag-to-trash tile eraser system (3 chances per game)
> - Per-difficulty high score persistence (localStorage)
> - Mobile-responsive layout with touch swipe controls
> - Unit-tested game engine (slide, merge, spawn, game-over detection)
>
> **Estimated Effort**: Medium
> **Parallel Execution**: YES — 4 waves + final verification wave
> **Critical Path**: Task 1 → Task 3 → Task 11 → Task 13 → F1-F4

---

## Context

### Original Request
开发一个基于Web的小游戏2048，三种难度（简单、普通、困难），记录最高分，3次复活/回退机会。

### Interview Summary
**Key Decisions**:
- **技术栈**: React + TypeScript + Vite，纯CSS（无UI库）
- **难度设计**: 简单=6×6棋盘，普通=4×4经典，困难=4×4+新方块可出现8
- **胜负规则**: 无目标制，所有难度玩到不能动为止（无2048获胜门槛）
- **撤销机制**: 3次"消除"机会，将方块拖拽到垃圾桶区域来清除格子
- **UI风格**: 原版2048简约风格（致敬Gabriele Cirulli原版设计）
- **测试**: 包含核心游戏逻辑单元测试
- **移动端**: 包含触摸滑动操作 + 响应式布局

### Scope Guardrails (自检)
- [x] 所有难度均不设定目标值（玩到不能移动为止）
- [x] 消除是拖拽到垃圾桶，不是点击撤销上一步
- [x] 最高分按难度分别记录
- [x] 纯前端应用，无后端
- [x] 不包含PWA、深色模式、音效、多人模式

- [ ] 3. **Core game engine (pure logic)**

  **What to do**:
  - 创建 `src/core/GameEngine.ts`，实现以下纯函数（不依赖DOM、无副作用、接受RNG参数）：
  - **`createEmptyBoard(size: number): number[][]`** — 创建 size×size 的零矩阵
  - **`getEmptyCells(grid: number[][]): {row: number, col: number}[]`** — 返回所有空格坐标
  - **`spawnTile(grid: number[][], rng: () => number, config: DifficultyConfig): number[][]`** — 在随机空位生成新方块，根据概率分布选择值。返回新grid
  - **`slideRow(row: number[]): { row: number[]; scoreGain: number }`** — 一行左移核心算法：
    1. 过滤掉0（压缩）
    2. 从左到右扫描，相邻相等值合并（i+=2 跳过已合并）
    3. 右侧补0
  - **`moveLeft(grid: number[][]): { grid: number[][]; scoreGain: number; moved: boolean }`** — 所有行执行 slideRow
  - **`moveRight(grid)`** — 反转行 → slideRow → 反转回来
  - **`moveUp(grid)`** — 提取列 → slideRow → 放回
  - **`moveDown(grid)`** — 提取列反转 → slideRow → 放回
  - **`move(grid: number[][], direction: Direction): { grid: number[][]; scoreGain: number; moved: boolean }`** — 统一调度入口
  - **`isGameOver(grid: number[][]): boolean`** — 无空格且无相邻相同值
  - **`getMaxTile(grid: number[][]): number`** — 当前棋盘最大值
  - **`eraseTile(grid: number[][], row: number, col: number): number[][]`** — 清除指定格子
  - 函数签名要注入 `rng: () => number` 以提高可测试性

  **Must NOT do**:
  - 不要使用 `Math.random` 硬编码 — 通过参数注入
  - 不要引用任何 DOM/React API
  - 不要存储状态 — 所有函数是纯函数，输入→输出
